# Multi-region brain donor-by-region distribution

This analysis reproduces Figure 4e from aggregate counts of globally
cell-type-specific TR loci per donor and brain region. `has_sample` explicitly
distinguishes an unassayed donor-region combination from an assayed zero.

Run:

```bash
python scripts/plot_donor_region_distribution.py
```

`results/figure_4e_source.png` is the exact retained source panel.
