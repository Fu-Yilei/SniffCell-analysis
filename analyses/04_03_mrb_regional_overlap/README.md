# Multi-region brain regional overlap

This analysis covers Figure 4d and Supplementary Figure 16. It uses aggregate
shared/union counts for each brain-region pair, both overall and stratified by
cell type. No locus-level call table is included.

Run:

```bash
python scripts/plot_regional_overlap.py
```

Exact retained assets are `results/figure_4d_source.png` and
`results/supplementary_figure_16_source.png`.
