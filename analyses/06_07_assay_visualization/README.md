# Assay-aware SniffCell visualization

Read [the blog update](BLOG_UPDATE.md) for the bmsa FGF14 illustration,
its explicit one-read exclusion, display semantics and implementation details.
The figure was generated with the production `sniffcell viz` command on the
5hmC development branch, not with the earlier prototype renderer.

Contents:

- `results/`: the PNG and PDF illustration.
- `scripts/render_example.py`: reproduction command wrapper requiring authorized inputs.
- `manifest.json`: public source/version metadata, figure checksums and selection counts.

This is a software-display illustration, not a manuscript panel or an accuracy
benchmark. It intentionally retains the native SniffCell title and figure
notes, including the explicit display-exclusion notice. Earlier FANS benchmark
results remain unchanged.
