# 2.3 PBMC structural-variant example

Supplementary Figure 14 is a manually curated IGV screenshot, not a derived
statistical plot. The exact source PNG is therefore retained as the result and
its checksum is verified by a small reproducibility script. No VCF, variant
table, BAM, or server path is included.

Run:

```bash
python scripts/verify_figure_asset.py
```

The current manuscript caption calls this a PBMC1 example, while the retained
curated asset is labelled `pbmc2 T-cell` at the TRB locus. That provenance
discrepancy is documented rather than silently relabelled.
